# Tic-Tac-Toe AI

## Description
This project is a Tic-Tac-Toe game developed using Python.
The AI player uses the Minimax algorithm to make the best possible moves.

## Algorithm Used
- Minimax Algorithm

## Technologies Used
- Python

## Features
- Human vs AI gameplay
- AI-based decision making
- Win detection
- Draw detection
- Interactive command-line interface

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

python tic_tac_toe.py

## Output
The user plays as X and the AI plays as O.
